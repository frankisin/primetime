Practice Problem: Banking System

You are implementing an in-memory banking system.
Process a list of queries in order. Each query returns a string.

Core entities
Accounts are identified by accountId (string).
Balances are integers (use int).
System starts with no accounts.

Rules

An operation that fails must not change state.
All outputs are strings.
If an account does not exist, treat it as invalid.

Operations
1) CREATE_ACCOUNT accountId
Create a new account with balance 0.
Return:
"true" if created successfully
"false" if the account already exists

2) DEPOSIT accountId amount
Add amount to account balance.
Constraints:
amount is a positive integer
Return:
New balance as a string (e.g., "125")
"false" if account does not exist

3) WITHDRAW accountId amount
Subtract amount from account balance.
Constraints:
amount is a positive integer
Balance may not go negative
Return:
New balance as a string
"false" if account does not exist OR insufficient funds

4) TRANSFER fromAccountId toAccountId amount
Move amount from one account to another.
Constraints:
both accounts must exist
amount is a positive integer
fromAccountId must have sufficient funds
If transfer fails, neither account changes
Return:
New balance of fromAccountId as a string (after transfer)
"false" if invalid accounts OR insufficient funds OR same account transfer is not allowed (see note)
Note (common OA rule): If fromAccountId == toAccountId, return "false".

5) TOP_ACCOUNTS k
Return the top k accounts by balance, sorted by:
balance descending
accountId ascending (lexicographic) as tie-breaker
Format:
"accountId(balance)" joined by commas
If fewer than k accounts exist, return all of them
If no accounts exist, return ""

Example:
"alice(200),bob(150)"

Output
Return a list of strings, one per query, in the same order.

Example Queries
CREATE_ACCOUNT alice
CREATE_ACCOUNT bob
DEPOSIT alice 200
DEPOSIT bob 150
WITHDRAW bob 20
TRANSFER alice bob 50
TRANSFER bob alice 1000
TOP_ACCOUNTS 3

Expected outputs
"true"
"true"
"200"
"150"
"130"
"150" (alice becomes 150, bob becomes 180)
"false" (insufficient funds; no state change)
"bob(180),alice(150)"
